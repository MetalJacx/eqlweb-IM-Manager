Pick a category below, choose which classes and items to keep, then download a loot filter file you can merge into your own.

Item IDs are cross-referenced from eqlfilter.com's item database, and drop/live status from eqlwiki.com's per-item drop location and content-era data. Drops are confirmed dropping in a live Classic zone right now. Not Live Yet items (Epic Quest only) would drop the same way, but are locked behind the still-unreleased Kunark expansion. Quest Rewards are handed over directly by an NPC and never appear in a loot window, so they're shown for reference only and can't be added to a filter. Within Drops/Not Live Yet, an item greyed out with an ID unknown tag is missing a known Item ID and can't be added yet either.
